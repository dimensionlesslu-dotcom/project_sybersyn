## 一、为什么是控制论？

控制论 (Cybernetics) 是研究**通信、反馈与控制**的交叉学科——它研究"系统如何通过反馈自我校正达成目标"。这门学科诞生于二战期间（维纳，1948），在导弹制导、自动化、管理学、生物学、认知科学中都有广泛应用。

AI Agent 执行复杂任务的行为模式，与控制系统的核心问题高度同构：

| 控制论概念 | AI Agent 对应 |
|------------|--------------|
| 参照输入 r(t) | 用户需求 + 验收标准 |
| 控制器 | Agent 的计划与策略 |
| 被控对象 | 任务产物（代码/文本/方案） |
| 反馈回路 | 测试→偏差检测→修改 |
| 干扰 | 隐含假设、不完整信息、环境变化 |

**核心理念**：不赌一次性计划的完美，赌闭环迭代的自我校正。

## 二、一阶回路：钱学森工程控制论

### 2.1 闭环传递函数

一切控制系统形成闭环后，前向线路与反馈线路构成统一的系统传递函数（《工程控制论》§3.7）：

> **F(s) = F₁(s) / (1 + F₁(s)F₂(s))**

开路控制（无反馈）的时间常数大、精度低；引入反馈后，有效阻尼系数增加，时间常数和稳态误差均降低。这意味着：**有反馈的系统比开路系统更稳定、更精确。**

### 2.2 对 AI 任务的意义

在 SKILL.md 中，闭环六阶段（计划→测试₁→反馈→修改→测试₂→输出）就是这个反馈回路的具体实现。每一步依赖前一步的输出，形成自校正循环。

## 三、二阶回路：冯·福斯特的二阶控制论

一阶回路回答"偏差从哪来、如何修正"——它假设观察者站在系统外部，参照输入 r(t) 是正确的。

二阶回路回答"参照输入 r(t) 是否正确、我的信念是否在欺骗我"——它认识到**观察者是系统的一部分**。

> "一阶控制论：被观察的系统。二阶控制论：观察系统。" — Heinz von Foerster (1974)

在 SKILL.md 中，二阶审计（第 5 节）就是这个二阶回路的具体实现。

## 四、必要多样性：阿什比定律

> **Only variety can absorb variety.** — W. Ross Ashby (1956)

如果控制器的内部状态数小于受控对象的可能状态数，控制必然失败。对 AI 任务的意义：

- L3/L4 任务中，单一策略不足以覆盖所有可能情况
- 必须"分而治之"（分解为 L1/L2 子任务）
- 或升级到综合集成方法（研讨厅）

SKILL.md 中的"准入规则"（每个核心风险点至少一种纠错策略）是对阿什比定律的操作化。

## 五、活系统模型 (VSM)：比尔的管理控制论

Stafford Beer 的活系统模型 (Viable System Model) 将组织划分为五个子系统：

- **S1 操作**：做具体事情
- **S2 协调**：防止 S1 之间冲突
- **S3 内部控制**：资源分配与监控
- **S4 外部智能**：扫描环境，规划未来
- **S5 政策**：定义身份与方向

在 SKILL.md 中，VSM 在 L3+ 任务中作为辅助诊断工具使用——当出现"局部正确、整体变坏"时，用 VSM 视角定位问题。

## 六、开放的复杂巨系统 (OCGS)：钱学森综合集成方法

钱学森在 1980s-1990s 提出"开放的复杂巨系统"概念：

- 子系统异构、层次化
- 与环境持续交换信息
- 可能出现涌现行为
- **不能用单一形式化模型描述**

综合集成方法（研讨厅体系）将**人的定性判断**与**机器的定量推演**结合：

1. 对同一对象建多个不同结构的模型
2. 不追求唯一正确模型
3. 机器做定量推演，人做定性判断
4. 每轮显式声明假设，下轮挑战其一
5. 收敛 = 各视角不再产生新的定性分歧

这对应 SKILL.md 第 7 节"研讨厅"模式。

## 七、其他理论基础

### 7.1 自创生与结构耦合（Maturana & Varela, 1980）

自主对象（用户/团队/Agent）不是可被"指令"控制的——控制信号对于它们来说只是"扰动"，它们按自己的结构响应。因此：

- 扰动→观察其结构响应→适配，胜过多轮硬指令
- 对应 SKILL.md 第 8 节"结构耦合"

### 7.2 学习层级（Bateson, 1972）

- **零阶学习**：对单一刺激的固定反应
- **一阶学习**：在固定目标下改进策略（对应一阶闭环）
- **二阶学习**：学习如何学习——改变学习策略本身（对应二阶审计）
- **三阶学习**：改变"改变学习策略"的方式（对应研讨厅）

### 7.3 POSIWID（Beer）

> "系统的目的不在于它声称要做什么，而在于它实际做了什么。"

在 SKILL.md 中，POSIWID 是二阶审计的一项可选检查——当"声称目标"与"实际行为"出现持续偏差时触发。
